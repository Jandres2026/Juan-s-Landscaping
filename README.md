# Juan's Landscaping Website Demo

This is a simple multi-page website demo for Juan's Landscaping Lawn Care & Services.

## Pages
- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `contact.html` — Contact and estimate request form

## Open it in VS Code
1. Extract the ZIP file to a folder you can find.
2. Open that folder in VS Code (File → Open Folder).
3. Open `index.html`.
4. If you have Live Server installed, right-click `index.html` and choose **Open with Live Server**.
5. Use the navigation menu to test the four pages.

## Important notes before showing the customer
- The phone and email are based on the business card details provided. Please confirm they are correct with Juan.
- The contact form currently opens the visitor's default email app with the message filled in. It does not automatically send or store submissions. To receive requests directly from the website, connect a form service such as Formspree and update the form configuration.
- Photos are loaded from Unsplash, so an internet connection is needed for those images and Google Fonts. Replace them with approved customer photos before launching the final site.
- Confirm the service list, service area, business name, and all contact details with the customer before publishing.

## Project folders
- `css/style.css` — shared styling for all pages
- `js/script.js` — mobile navigation, copyright year, and estimate form behavior
- `images/` — place locally supplied business photos here
